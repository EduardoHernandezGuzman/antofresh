# AntoFresh

Landing page estática lista para GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `script.js`
- `assets/antofresh-logo.png`

## Cómo subirla a GitHub
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos manteniendo la estructura de carpetas.
3. Entra en **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/root`.
6. Guarda los cambios.
7. GitHub publicará la web en unos segundos o minutos.

## Personalización rápida
- Teléfono: cambia `900 123 456` en `index.html`.
- Correo: cambia `hola@antofresh.es` en `index.html`.
- Textos: edítalos directamente en `index.html`.
